### 🛠️ Tecnologias Utilizadas
- [Kotlin](https://kotlinlang.org/)
- [Jetpack Compose](https://developer.android.com/jetpack/compose)
- [Material Design 3](https://m3.material.io/)
- [Coil](https://coil-kt.github.io/coil/) (Carregamento assíncrono de imagens)

---

### 🚀 Como Executar o Projeto
1. Clone este repositório:
   ```bash
   git clone https://github.com/joao-ce746/Quem_Eu_Sou.git
   ```
2. Abra o diretório no **Android Studio**.
3. Aguarde a sincronização das dependências do Gradle.
4. Execute o projeto em um emulador ou dispositivo Android conectado.
